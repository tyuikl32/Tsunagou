# D193 控制台自己留一份"上次看到的样子"；确认完工后关掉只能在做项目时用的入口

日期：2026-10-03
状态：已实施

## 决定

两件与"项目结束"有关的事，一起定下来。

### 一、控制台留一份记录（谁搬运过什么、什么时候）

控制台读项目一路是"页面 → 中间层 → HTTP + 令牌 → 项目 daemon"（[console.md](../implementation/console.md) 的不变量）。
项目一结束 daemon 就没了，于是名单、任务、审计、存档点全变空 —— 项目自己的库还在磁盘上，但按那条不变量
中间层不去读它。

所以让**中间层记下自己搬运过的东西**：`~/.tsunagou/console-history/<项目>.json`，一个出口一条，
内容是**最近一次看到的回答 + 什么时候看到的**。daemon 不在了就把这份拿出来顶上，并在回答里说清
它是记录（聚合视图放在 `history`，页面自己直连的出口放在 payload 的 `_history`，HTTP 头
`X-Tsunagou-History` 带同一时刻）。删项目时**无条件**连它一起删。

三条纪律（它们决定这功能是"方便的存档"还是"会骗人的第二真相"）：

1. **只顶"连不上"这一种情况**。daemon 还在、只是拒绝了（4xx/5xx）—— 那是**现在**的答案，一字不改
   地送回去；拿旧记录盖住一个活的拒绝，比留空难查得多。写动作永远要真 daemon，永远不用记录顶替。
2. **只在读不到时出现，且必须带记录时刻**。页面写「上次记录（记录到 …）」。记录只能由"daemon 活着"
   刷新（否则看一眼列表就把时刻刷成现在，那它就再也说不出"最后活着是什么时候"）。
3. **有界**。长列表截断（并写明截断了）、超大的一份只留一句说明、坏文件读成"没有记录"、写不进去
   只当没记 —— **绝不影响本来能看的读取**。

### 二、确认完工之后，关掉"只能在做项目时用"的入口

判据是项目自己那份 `.tsunagou/project.json` 里的 `lifecycle`（用户确认完成那一步写下的，
[handlers.py](../../src/tsunagou/application/handlers.py)）：**daemon 停着也判得出来**。

`completed` / `archived` 时页面上不再画：

- **接入 Agent**（Agent 管理页那个加号，与向导第三步的小加号）；
- **立即存档**（验收与存档点那一屏的存档卡）；
- **设为主 Agent**（Agent 卡片上的动作）。

**不关**：改昵称、删除 Agent、删除项目、**校验**存档点、**重试存档** —— 收尾之后恰恰还要做这些
（完工本身就要落一个存档点；万一那次没存成，重试正是最该做的事）。

这是**页面级**的关闭：后端照旧接受这些命令。理由是"完工"是协作语义，由人确认，改动后端判定会牵动
完工那一步自己的存档动作；要改成机械拒绝是另一件事（得先想清完工时那次存档怎么办）。这一条写在文档里，
不含糊。

## 为什么这么做（而不是别的形状）

| 备选 | 为什么不选 |
|---|---|
| daemon 停了就直接读项目自己的 `state.sqlite3` | 违反上面那条不变量：中间层从此要懂 daemon 的 schema 与投影，schema 一漂移就是两份会分叉的真相；还有 WAL 与文件锁。 |
| 需要看时把 daemon 再起起来 | 为了"看一眼"启动一个进程；项目目录挪走就没得读；"结束了的项目又被起起来"与人的直觉相反。可作补充，不宜当唯一手段。 |
| 记录里连消息正文一起留 | 正文本来就不在页面/中间层（消息出口只给摘要行与 `payload_digest`，正文只对**收件人本人**开放）。复制过来等于多一处泄漏面，而且中间层本来也拿不到。要"以后还能看全"是**导出/封存**那件事，得单独决定。 |
| 完工后由后端机械拒绝这些命令 | 见上一节最后一段：会影响完工那次存档，属于另一个决定。 |

## 落点

- 记录：`src/tsunagou/console/history.py`；接在三个读取点（聚合视图、页面直连的中转、项目列表）与
  `projects.forget`；`console/app.py` 的 `_resolve_readable` 让"没跑但有记录"的读继续走下去。
- 页面：`web/assets/js/behavior.js`（`recordStamp` / `recordText` / `recordNote` / `recordDetail`、
  `projectFinished`），只在"读不到"的分支里出现，只动 `display` 与文案。
- 验收：单测 `tests/unit/test_console_history.py`；中间层 `tests/unit/test_console_relay.py`（记录顶上、
  活的拒绝不被顶掉、写动作不被顶掉、从没记录过照旧报未启动、删项目连记录一起删）；前端
  `web/tests/behavior.smoke.test.ts`（完工隐藏、未完工照旧、卡片写"上次记录"、面板写记录时刻）；
  冒烟最后一条：**真 daemon 停掉之后同一屏仍从记录里答出全部来源**。
