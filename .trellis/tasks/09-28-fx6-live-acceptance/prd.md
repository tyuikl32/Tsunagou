状态：in_progress；FX-R07，集成 FX-R01–06。依赖 FX1–FX5；最终 Sega 业务回归另需 FX7。实际验收结论见 implementation-progress.md。

## 目标

在全新协调状态验证修复后的完整产品，不重放旧身份或迁移旧数据库。原实测材料保留作比较，未通过项不得由构建成功替代。

## 验收

| ID | 结果 |
| --- | --- |
| A1 | 安装产物在业务目录独立启动，主 Agent 加两名 Worker 身份独立；其中两名 Worker 为用户手动创建的 Desktop 会话 |
| A2 | 会话结束当前回合后，经 daemon 消息自动开始原会话新回合并处理任务；用户不代发继续 |
| A3 | main 发布范围不冲突的任务，Worker 各一次 begin→实际工作→submit；main 审查，有可观察业务成果 |
| A4 | 长回合不续租、不重复选择工作区；断线/daemon 重启保持 owner，显式回收后旧 Attempt 不能提交 |
| A5 | 真实分歧经报告/协商后形成契约；契约终态和取消回归通过，不强制无分歧任务制造报告 |
| A6 | 主 Agent 等用户重大决定时，不相关任务继续；相关 Worker 保存进展结束回合并挂起，后续消息能恢复 |
| A7 | CLI 能查部署/执行/提交/审查起止、失败和触发来源；trace 关联真实消息，token 未知如实显示 |
| A8 | 正常样本和损坏/截断 BTID 经真实 HTTP/页面得到正确结果；用户未确认重大交付前不宣称最终完成 |

只验证代码和事实，不要求用户填写能力问卷。实施见 [implement.md](implement.md)；样例组织和留档见 [design.md](design.md)。
