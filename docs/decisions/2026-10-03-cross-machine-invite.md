# D190 跨机器接入：一律"主机发邀请"（A 流程），远端一条命令收下

日期：2026-10-03
状态：已实施（1a / 1b / 1c）

## 决定

跨机器接入只有**一个**用户动作：主机这边发一张邀请，远端那边把邀请收下。没有"远端敲门、主机点同意"
的第二条路 —— 两条路并存会让人在两套心智模型之间切换，而其中一套（待批准）还要多出一个状态机、
一个短码/公钥体系，收益却只是省下"远端先报一次号"。

配套的三条：

1. **邀请是机密，像传密码那样递**。邀请内容里带着那张一次性票，所以它**必须**能被人看见并转交
   （这与"票的明文永不进页面"的旧约定相反，是一处**有意**的例外）。缓解手段就是票本身的限制：
   一次性、10 分钟、只能签子 Agent、用过即废。
2. **远端只写自己这台机器的东西**。票、身份、桥的启动配置都落在远端的私有目录
   （`~/.tsunagou/remote/<adapter>-<hash>`），代码副本里只放宿主自己的配置项。项目仍然只有主机上那一份，
   远端**不会**长出第二份协作数据。
3. **远端自己报名**。主 Agent 必须和协调中心同机，所以跨机器那一个只能是子 Agent（主机侧直接拒绝
   `--role main`）。

## 身份从哪来（1a / 1c 的分界）

票必须绑死身份，而身份的一半是"这条会话在宿主眼里叫什么"：

| 宿主 | 会话名谁说了算 | 用户动作 |
|---|---|---|
| OpenCode | **主机**（起 `ses_<名字>`） | 直接发邀请 |
| Codex / DeepSeek Harness | **只有宿主自己**（`CODEX_THREAD_ID` / `DSH_SESSION_ID`） | 远端先 `agent whoami` 报号 → 主机把号填进表单 → 发邀请 |

所以"统一成发邀请"之后，Codex / DSH 只多一次**复制一串非机密编号**；页面为这一格只在
"位置＝网络 **且** 厂商是这两个"时出现。DeepSeek Harness 的聊天只能通过插件动手，所以插件多了一个
`tsunagou_remote`（`whoami` / `import`）动作。

若将来要连这一次复制也去掉，那需要**不记名邀请**（谁先兑谁得、一次性、短时效）：那是协议级决定
（放弃"票绑身份"这条不变量），本次**没有**做。

## 协调中心：地址与端口

- 端口**固定 2810**，方便远端和隧道写死一次；被占用时**不失败**：启动打一条警告，改用一个随机的空闲
  端口，并且**最终真正使用的端口**才是写进邀请的那一个（`--port 0` 仍表示"随便给一个"，不报警告）。
- **监听地址 ≠ 对外可达地址**：`--host/--port` 决定"在哪些网卡上听"，`--advertised-url` 决定
  "远端该拨哪个号"。绑 `0.0.0.0` 时这两者必然不同（`0.0.0.0` 不是远方能拨的地址，直接拒绝）。
  写回环、或写局域网地址却只监听回环，都会在启动时用一句人话说出来。

## 网络层

不自研加密，也不自动配置：同一台机器上多 Agent 协作走回环（不需要加密），跨机器时**由使用者**套一层
现成的加密通道（内网 / WireGuard / Tailscale / SSH 转发）。协调中心端口不进公网。会话令牌是 Bearer
形式，明文通道上会被嗅探冒用 —— 这正是"必须走加密通道"这条红线的来源。

## 远端标记怎么显示

远端导入时自报一个机器名（`agent import --machine`，缺省取该机主机名），随入席时**现成的**
`descriptor_ref` 字段上送（该字段此前无人使用）。协调中心把它记在 Agent 上，名单出口公布为 `machine`，
页面把它写成「网络在线 · 工位-七」。（**2026-10-05 起**：徽标那两个词改成「**在线 / 离线**」，来源是 daemon 按心跳算出的 `online`；机器名不再跟在徽标后面，改显示在 Agent 详情/修改窗口的「在哪台机器」那一行。见 `web/method.md` 的徽标一节。）

它是**自报**，不是认证：不参与任何权限、角色、范围判断；乱填（超长、含换行、类型不对）只当没报，
绝不让入席失败。本机接入从来不填这一项 —— 页面正是靠"没有"来判断不需要画远端标记。

## 落点

- 邀请格式：`src/tsunagou/platform/remote_invite.py`
- 主机侧：`agent invite`；页面/中间层：`console/enrollment.py::_prepare_network`
- 远端侧：`agent import`（含 Codex / DSH 的路由文件）、`agent whoami`
- 宿主插件：`packages/adapter-deepseek-host/index.js`（`tsunagou_remote`）
- 机器名：`handlers.enroll`（读 `descriptor_ref`）→ `authority.Agent.machine` → agents 出口 → 页面徽标
