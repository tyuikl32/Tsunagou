# FX-D02：直接重构，不做旧数据或客户端迁移

日期：2026-09-28。确认依据：用户选择统一升级，并补充“无需保留历史记录和 Agent 身份，无需创建迁移。直接改”。状态：设计约束已确认，产品代码尚未修改。

## 决策

1. 本次新版 daemon、bridge、CLI、Skill 统一发布与使用，不维护旧写协议、旧 MCP 工具或混合版本兼容层。
2. 不编写旧数据库、旧 checkpoint、旧会话或旧 Agent 身份的迁移器；不要求原项目状态和身份在此次升级后延续。
3. 新版验收从全新协调状态开始，Agent 按新版接入流程获得新身份。历史测试材料只作为问题来源，不作为新版运行依赖。
4. 可以直接移除过时的续租命令、字段、提示和测试；不留下永远返回成功的兼容空实现，也不靠扩大 TTL 维持旧设计。
5. 新版本自身仍保留项目运行记录、时间戳、消息和同版本重启恢复。用户取消的是此次跨版本迁移成本，不是未来运行中的持久化功能或会话身份边界。
6. 此决定不要求现在删除旧实测目录、数据库或 Git 历史。开发时使用新状态目录即可，清理不成为设计和实施前置条件。

## 范围影响

[修复方案](../implementation/live-test-repair-plan.md)及所属任务删除迁移脚本、旧记录修复、双写、旧新格式兼容测试和保留旧 Agent 身份的要求。数据模型和字段名可直接按新语义统一，但不为纯改名扩大无关模块重构。

继续复用已验证的存储、事件、CLI 和协议生成基础设施；不因拒绝兼容而重新实现整套底层。Trellis 的旧任务记录及本轮复盘文档照常用于开发追溯。
