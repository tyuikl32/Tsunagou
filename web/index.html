关于 Tsunagou

v1.0.0 Beta

Tsunagou 是一个多 Agent 协作调度系统，旨在通过文档交换、契约更新、权限管理等调度机制，解决多个 Agent 在同一协作上共同协作时产生的冲突，使他们能够“看见彼此”、像人类一样协作，从而提升效率。

开发人员：骆宣卓、陈林榕、张子宸、大肥鱼、GPT-6
