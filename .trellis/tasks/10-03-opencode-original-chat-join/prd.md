# OpenCode 原对话最小接入

用户已在本会话明确批准完整设计、实施和创建任务。首次安装允许重载原对话一次；不需要再次规划审批。

## 目标与要求

任意目录的当前 OpenCode 对话接入控制台所选项目。控制台只保存申请；身份由真实宿主调用上下文提供；CLI 认领后签票；原对话 MCP 调用成功才显示 arrived。

- 用户级无凭据工具和共享 MCP 一次安装，新增接入只写私有路由。
- tsunagou_connect 不接受模型提供身份、项目、角色或命令。
- 项目/角色由匹配 OpenCode 的申请决定，不回退 cwd；同会话重试、跨会话隔离、跨项目拒绝覆盖。
- 保留 Codex 默认行为、DSH、旧项目接入和跨机器流程；旧绑定冲突明示，不隐式创建第二身份。
- 不做批量迁移、自动唤醒、热加载、新状态机或通用宿主框架。

## 验收

1. 本机 2.0.18 真实宿主：用户级入口能取 sessionID，MCP 元数据同 ID，重载后 ID 不变；不符合则停止并报告，不扩建兼容层。
2. 无关目录的已有对话接入申请项目/角色；无申请不创建项目。
3. 第二对话不能抢申请或借用凭据；重复接入和重载保持身份。
4. helper 成功仍等待，原对话 ready context + 精确回执和新鲜名单才 arrived。
5. 中文路径、配置幂等/冲突、相关 Codex/DSH 回归和文档验证通过；未实测不得声称通过。
