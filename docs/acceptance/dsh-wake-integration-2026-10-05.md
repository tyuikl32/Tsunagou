## 本次源码集成

标准 npm 插件随源码安装交付，Desktop prepare 复用正式插件加载入口。新增托管私有配置模式，密钥及认证后原会话绑定由初始化/接入流程写入，插件逐请求读取；不把密钥写进 profile 或环境变量。实际插件实例发布无密钥 runtime 地址，客户端只访问固定 loopback 路由且不使用代理或重定向。

`coordination__wake_status` / `coordination__wake` 沿用现有调用者、消息、项目、原会话与重复执行检查。DSH 通过插件后台 queue，OpenCode 及 Codex 既有路径不变。受理不被标为启动，`unloaded` 不被冒充 idle。hook 指向插件入口，并将初始化缺失与宿主本身不支持分开。

初始化是配置完成，不是实机唤醒成功。旧独立插件加载块明确报冲突，不自动覆盖或加载第二份路由。使用标准 Tsunagou 源码安装布局，与已有 identity provider 一起从长期安装目录加载；Python wheel 本身不是完整 Node 宿主安装。
